# Projetos de aprendizagem

Repositório de projetos de estudo com Java, Spring Boot e interfaces web. Cada projeto tem sua própria configuração e pode ser executado separadamente.

| Projeto | Objetivo | Tecnologias principais | Java |
| --- | --- | --- | --- |
| [Sistema Biblioteca](sistema-biblioteca/) | Acervo, leitores, empréstimos e devoluções | Spring Boot, Spring Data JPA, H2, HTML, CSS e JavaScript | 21 |
| [Sistema E-commerce — Pague Mais](sistema-ecommerce/) | Loja web com catálogo, clientes, pedidos e pagamentos | Spring Boot, Spring Security, JWT, JPA, HTML, CSS e JavaScript | 17 ou superior |
| [Sistema Estacionamento](sistema-estacionamento/) | Controle de vagas, entradas, saídas, tarifas e recibos | Spring Boot, Spring Security, JWT, JPA, H2, HTML, CSS e JavaScript | 21 |
| [SPBank](spbank/) | Aplicação bancária de estudo com contas, transferências e PIX | Spring Boot, JPA, MySQL, Flyway, HTML, CSS e JavaScript | 25 |
